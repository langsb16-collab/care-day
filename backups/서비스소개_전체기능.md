# 뇌질환케어 (cashiq.org) - 전체 서비스 소개

## 🎯 플랫폼 개요
**"뇌질환 환자와 가족을 위한 국내 유일 통합 케어 플랫폼"**

뇌출혈·뇌경색, 치매, 파킨슨병 환자와 보호자가 필요한 모든 정보와 서비스를 한 곳에서 제공하는 종합 의료 정보 플랫폼입니다.

---

## 🆕 신규 추가 기능 (2026.01)

### 1️⃣ 질병별 맞춤 케어 시스템
**치매 관리 가이드**
- 단계별 특징 (초기/중기/말기)
- 가족 행동 가이드 (✅ 해야 할 것 / ❌ 피해야 할 것)
- 주변 전문병원 찾기
- PDF 가이드 다운로드
- 카카오톡 공유 기능

**파킨슨병 관리 가이드**
- 운동/비운동 증상 설명
- 파킨슨병 운동 가이드
- 복약 관리 체크표
- 자가 체크 리스트 (8개 항목)
- 전문병원 연계

### 2️⃣ 전국 전문병원 DB
**200+ 치매·파킨슨 전문병원 구축 예정**
- 지역별 분류 (서울/경기·인천/충청/호남/영남/강원·제주)
- 병원 정보: 전화/주소/진료과
- 검증 등급 표시 (A: 전문클리닉 운영 / B: 진료 가능 / C: 확인 필요)
- 원클릭 전화 연결
- 카카오맵 연동
- 간병 상담 즉시 연결

### 3️⃣ 간병인 매칭 플랫폼
**24시간 상담 가능 (1588-0000)**
- 방문 간병 (시간당 15,000원~)
- 병원 간병 (1일 130,000원~)
- 단기 간병 (4시간 60,000원~)
- 평균 2~6시간 내 신속 배정
- 간병인 교체 요청 자유
- 365일 24시간 상담·배정
