# 뇌질환케어 (cashiq.org) - 서비스 소개

## 핵심 차별점 (타사 대비 독보적 기능)

### 1️⃣ 질병별 맞춤 케어 시스템 (신규)
**치매·파킨슨병 전문 가이드**
- 단계별 관리법 (초기/중기/말기)
- 가족 행동 가이드 (해야 할 것/피해야 할 것)
- 자가 체크리스트 제공
- 복약 관리 체크표 다운로드
- 운동 가이드 (파킨슨병)

### 2️⃣ 전국 전문병원 DB (신규)
**치매·파킨슨 전문병원 200+ 구축 예정**
- 지역별 분류 (서울/경기/광역시)
- 병원 정보: 전화/지도/진료과
- 검증 등급 표시 (A/B/C)
- 원클릭 전화/지도 연결
- 간병 상담 즉시 연결

### 3️⃣ 간병인 매칭 플랫폼
**24시간 상담 가능**
- 방문 간병 (시간당 15,000원~)
- 병원 간병 (1일 130,000원~)
- 단기 간병 (4시간 60,000원~)
- 2~6시간 내 신속 배정
- 교체 요청 자유

### 4️⃣ 통합 정보 원스톱
**병원 → 재활 → 간병 → 지원정책 → 보험**
- 3,500+ 병원 DB
- 1,200+ 간병인 네트워크
- 105+ 재활 영상
- 정부 지원정책 연계
- 민원 접수 시스템

### 5️⃣ 고령자 최적화 UX
**모바일 우선 설계**
- 큰 글자/큰 버튼
- 원터치 전화 연결
- JS 최소화 (안정성 극대화)
- 자동 야간 모드
- 스크롤 최소화

### 6️⃣ 가족 공유 기능
- 카카오톡 공유
- URL 복사
- PDF 다운로드 (준비중)
